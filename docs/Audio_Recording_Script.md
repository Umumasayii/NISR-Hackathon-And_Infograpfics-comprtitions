# Spoken summaries in Kinyarwanda: recording script

The website can play short spoken summaries recorded by a person. Nothing is generated by
text-to-speech, nothing plays by itself, and the transcript is always shown beside the player.
A summary appears only when `SCRIPTS/web/public/audio/manifest.json` lists it.

**Status:** no recording exists yet, so no player is shown. The Kinyarwanda lines below are
drafts and must be checked by a native speaker before recording. We have not tested the site
with people with limited literacy, so we make no claim that it works for them.

## How to add a recording

1. A native speaker checks and corrects the text, then records it (mono, 64 kbps MP3 or
   Opus, under 40 seconds, quiet room).
2. Save it as `SCRIPTS/web/public/audio/overview_rw.mp3`.
3. Add it to `manifest.json`, with the final text as the transcript:

```json
{
  "overview": {
    "file": "overview_rw.mp3",
    "reviewed": true,
    "transcript": {
      "rw": "<final Kinyarwanda text, exactly as recorded>",
      "en": "<English version of the same text>",
      "fr": "<French version of the same text>"
    }
  }
}
```

4. When a number on the page changes after a data rebuild, record the summary again.
